================================================================================
   HƯỚNG DẪN TẢI & CÀI ĐẶT FILE APK MOBILE (SFA / DMS BÁNH KẸO FMCG)
   Ứng dụng Android dành cho Nhân Viên Bán Hàng Thị Trường & Van Sales
================================================================================

1. TẢI FILE CÀI ĐẶT .APK TRỰC TIẾP VỀ ĐIỆN THOẠI ANDROID (KHUYÊN DÙNG):
   - Mở trình duyệt trên điện thoại Android, truy cập vào đường link GitHub Release:
     👉 https://github.com/tdngon01/ERP_ban_tap_hoa/releases/tag/v1.0.0-mobile

   - Hoặc bấm vào link tải trực tiếp file APK:
     👉 https://github.com/tdngon01/ERP_ban_tap_hoa/releases/download/v1.0.0-mobile/app-release.apk

   - Sau khi tải xong, bấm vào file "app-release.apk" trên thanh thông báo điện thoại:
     + Nếu máy hỏi "Cho phép cài đặt ứng dụng không rõ nguồn gốc?", chọn CÓ / CHO PHÉP.
     + Bấm "Cài đặt" (Install) -> Hoàn tất!

2. TỰ ĐÓNG GÓI BẰNG MÁY TÍNH CÁ NHÂN:
   - Nếu bạn có máy tính cài sẵn Flutter SDK:
     + Mở thư mục "apps/mobile-flutter" (hoặc giải nén Source_Mobile_Flutter_Ready_To_Build.zip).
     + Nhấp đúp vào file "Build_APK.bat".
     + File APK sẽ xuất hiện tại: build/app/outputs/flutter-apk/app-release.apk.

3. DÙNG TRỰC TIẾP TRÊN ĐIỆN THOẠI QUA MẠNG WI-FI (PWA KHÔNG CẦN CÀI ĐẶT):
   - Kết nối điện thoại và máy tính chung mạng Wi-Fi.
   - Mở Chrome trên điện thoại, gõ: http://[IP_WiFi_Máy_Tính]:3000
   - Bấm menu 3 chấm trên Chrome -> "Cài đặt ứng dụng" / "Thêm vào màn hình chính".
   - App sẽ xuất hiện ngoài màn hình chính điện thoại, chạy toàn màn hình độc lập!

4. GIẢ LẬP TRÊN APP DESKTOP:
   - Trên App Desktop, bấm menu "Giả Lập Mobile Sale SFA" để trải nghiệm đầy đủ:
     + Đi tuyến 5 bước viếng thăm tạp hóa
     + Bốc hàng lên xe & kiểm tra số lượng bánh tồn xe
     + Sổ ghi nhớ nợ hàng / hẹn ngày giao bù cho tiệm.
